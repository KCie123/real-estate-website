# Placeholder Images

This directory is where property and testimonial images should be placed. 

In a production environment, you would add real property images here with filenames that match those referenced in the JSON data files:

- `/images/property-1.jpg`
- `/images/property-2.jpg`
- `/images/property-3.jpg`
- etc.

For testimonials:
- `/images/testimonial-1.jpg`
- `/images/testimonial-2.jpg`
- `/images/testimonial-3.jpg`
- etc.

## Image Recommendations

- Property images should be 16:9 or 4:3 aspect ratio
- Recommended size: 1200x800 pixels
- Testimonial images should be square (1:1 aspect ratio)
- Recommended size: 400x400 pixels
- Use JPG format for photos
- Use WebP format for better performance if supported
- Optimize images for web to keep file sizes small
